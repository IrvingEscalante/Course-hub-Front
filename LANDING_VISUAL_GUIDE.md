## 📱 Responsive Breakpoints

### Desktop (>1200px)
```
Navbar: Links + Buttons
Hero: 2 Columnas (Texto | Card)
Features: 3 Columnas
Steps: Horizontal
Footer: 4 Columnas
```

### Tablet (768-1200px)
```
Navbar: Adaptada
Hero: 1 Columna stacked
Features: 2 Columnas
Steps: Horizontal con scroll
Footer: 2 Columnas
```

### Mobile (<768px)
```
Navbar: Simplificada (sin links)
Hero: 1 Columna, sin card
Features: 1 Columna
Steps: Vertical, sin flechas
Footer: 1 Columna
Botones: Full width stacked
```

## ✨ Animaciones Implementadas

### 1. Hero Card Flotante
```
Sube y baja continuamente
Duración: 3 segundos
Movimiento: ±20px en Y
```

### 2. Hover en Cards
```
Cuando pasas el ratón:
- Sube 8px
- Sombra aumenta
- Border color cambia a azul
```

### 3. Transiciones Globales
```
Duración: 0.3s
Ease: ease (suave)
Propiedades: all (todo)
```

### 4. Gradientes Animados
```
Hero Title: Blue → Green
Buttons: Dark Blue Gradient
Backgrounds: Subtle overlays
```
